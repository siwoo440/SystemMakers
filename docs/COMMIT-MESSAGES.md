## 이후 커밋 작성 기준

- 하나의 기능이나 관련 변경 묶음을 제목에 명확히 표시.
- 추가한 파일·기능, 수정한 동작, 제거한 항목을 실제 변경에 맞춰 본문에 기록.
- 테스트 명령과 결과를 기록하고 미실행 항목은 구분.
- 원문 비밀번호·DB 접속 정보·개인 환경 값을 메시지에 포함하지 않음.
- 관련 없는 파일이나 다른 팀원의 변경을 함께 커밋하지 않음.

예정된 2단계 제목은 `PHP 공통 처리와 메신저 웹 화면 추가`다. 본문에는 DB 연결·세션·CSRF·응답 처리, 웹 화면·접근 차단·실제 검증 결과를 기록한다. 세부 문구는 최종 구현 범위에 맞춰 작성한다.
