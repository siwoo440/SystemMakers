# 4단계 메시지 저장과 웹 연동 계획

사용자가 승인한 4단계 범위는 실제 채널에 대한 메시지 저장과 화면 전송 연동이다. [API.md](API.md)의 메시지 요청·응답, [DATABASE.md](DATABASE.md)의 트랜잭션·잠금 규칙을 따른다. 이전 대화 조회와 신규 폴링은 5단계다.

---
## 연결 계약

- POST /api/send_message.php: channel_id·content, 로그인·CSRF 검사, 성공 201 data.message.
- 메시지 공개 필드: id·channel_id·user_id·username·content·created_at. ID는 문자열, 날짜는 UTC ISO 8601.
- GET /api/get_channels.php: 로그인 사용자가 소속된 서버의 채널만 반환. 성공 200 data.channels 배열.
- 채널 공개 필드: id·server_id·server_name·name. 서버 ID와 채널 ID는 문자열이며 서버·채널 ID 오름차순.
- 새 계정은 빈 채널 목록을 반환하며 자동으로 서버에 가입시키지 않음.
- 개발 데이터는 기존 가입 계정을 지정하는 CLI에서만 생성. 운영 환경과 웹 호출 차단, 기존 계정·대화 삭제 없음.
