# 11단계 통합 검증 계획

목표: 7단계 규칙과 10단계까지 구현한 기능을 실제 가입→서버·채널·프로필→대화→탈퇴 흐름으로 검증하고 확인한 결함 수정.

구조: 기존 PHP·MySQL·프론트엔드 유지. 개발 DB33360은 원래 자료를 비교 보존하고 자동 검사는 전용33361 무작위 DB만 사용. 작업은 사용자 지시대로 main에서 직접 실행.

시작 기준: PHASE-7-RULES.md, API.md0.8, DATABASE.md0.5, 기존 전체150개 검사. 최종 로컬 결과: API 문서0.9·DB 문서0.5, 전체165개. 상세 근거는 [검증 보고서](PHASE-11-VERIFICATION.md) 참고.
