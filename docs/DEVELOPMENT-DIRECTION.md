## NAS 배포와 외부 접속

| 순서 | 남은 작업 | 완료 기준 |

| 2 | 외부 연결 경로 확정 | 공인 IP·CGNAT·이중 공유기 여부, 도메인 또는 DDNS, 80·443 포트 사용 현황과 포워딩 가능 여부를 확인한다. 직접 연결이 어려우면 소유자와 대안을 결정한다. |

| 4 | 실제 NAS에서 서비스 실행 | 검증한 ARM64 이미지 버전을 고정한다. 웹·Ratchet의 세션 공유와 저장 권한, DB 최소 권한, 볼륨 영속성, GD·업로드 한도와 MySQL 패킷 크기를 확인한다. |
| 5 | 다른 네트워크에서 두 계정으로 채팅 | 휴대폰 데이터를 사용해 HTTPS 로그인, WSS 구독, 채널·개인 대화의 양방향 전송, 첨부, 로그아웃과 권한 거절을 확인한다. 공인 인증서와 외부 접속을 검증한 웹 주소를 공유한다. |

배포 명령, 백업·복원과 롤백 절차는 [NAS 배포 안내](NAS-DEPLOYMENT.md)에 있다.

## 실제 기기와 운영 검증

- **화면과 브라우저** — Android·iPhone, Safari·Firefox·Edge의 대상 버전을 정한다. 세로·가로 화면과 소프트 키보드에서 입력·줄바꿈·초점·스크롤·모달 닫기·이전 대화 조회를 확인한다.
- **권한과 복구** — 두 계정과 여러 탭으로 초대·탈퇴·채널 삭제·프로필 변경·계정 전환을 검사한다. 소유자·관리자·회원별 접근, 소속 종료 뒤 초안·기록 정리, 통신 중단과 복구 후 누락 여부를 기록한다.
- **운영 기준** — 소유자와 비용, 동시 사용자 수, 허용 응답 시간, 백업 보관 기간과 복구 목표를 정한다. NAS 부하·장시간 연결·재시작·인증서 갱신·암호화한 외부 백업 사본 복구를 실제로 측정한다. 오래된 요청 제한 기록의 정리 주기도 정한다.
- **호환성** — PHP 8.3에서 Ratchet 0.4.4가 남기는 동적 속성 경고를 추적하고, 라이브러리를 갱신할 때 세션 공유와 연결 종료를 재검증한다.
- **결과 기록** — 화면 담당은 기기·OS·브라우저 버전과 화면 결과를, DB·인증 담당은 권한·저장·복원 결과를, 서버·채널 담당은 역할별 결과를 기록한다. 발견한 오류는 같은 기기와 회귀 검사에서 수정 여부를 확인한다. [로컬 통합 검증 기록](PHASE-11-VERIFICATION.md)

## 추가 최적화 후보

| 순서 | 현재 비용과 근거 | 변경안과 확인 기준 |
|---|---|---|
| 1 | 실제 채널 화면 함수를 가상 DOM으로 실행했다. 텍스트 50개에 1개가 도착하면 말풍선 51개와 요소 408개를 생성했다. 이어진 빈 조회는 둘 다 0개였다. | 메시지 ID로 기존 말풍선을 찾아 추가·변경된 항목만 갱신한다. 50+1에서 새 말풍선 1개, 같은 메시지 재수신 때 중복 0개를 확인한다. 이전 기록을 열 때 스크롤 위치, 이름·첨부 변경, 로그아웃 시 목록 비우기도 검사한다. |
| 2 | Ratchet은 정상 구독 연결마다 0.5초 주기로 계정과 참여 권한·최신 메시지를 조회한다. 코드상 연결당 초당 약 4회의 SELECT다. | NAS에서 동시 접속 수별 실제 조회 횟수와 알림 지연을 먼저 측정한다. 같은 주기의 중복 조회를 묶을 때도 연결별 세션 유효성과 알림 직전 참여 권한을 검사한다. |
| 3 | 위 50+1에서 텍스트만 도착해도 메시지 API와 첨부 목록 API를 각각 한 번 호출했다. 빈 조회 때는 메시지 API만 호출했다. | 기록 응답에 선택적 첨부 메타데이터를 함께 담는 방안을 비교한다. 파일 본문은 다운로드 API에 두고 권한 확인을 유지한다. 채널·개인 대화별 요청 수와 MySQL 실행 계획을 비교한다. |

`c7b8b39`의 로컬 화면 측정은 `tests/app-session.test.mjs`와 같은 실행 환경에서 함수 호출을 센 결과다. 실제 휴대폰의 표시 시간과 NAS의 처리량은 아직 측정하지 않았다. [브라우저 렌더링 비용](https://web.dev/articles/dom-size-and-interactivity) · [MySQL 실행 계획](https://dev.mysql.com/doc/refman/8.4/en/explain.html)
