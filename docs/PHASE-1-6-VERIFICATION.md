# 개인 대화·파일·프로필 검증 결과

검증일: 2026-11-11. PHP 8.3과 MySQL 8.4의 격리된 로컬 환경에서 실행했다. 기존 개발 DB를 변경하지 않았다.

---
## 자동 검사

- `node --test --test-concurrency=1`: 전체 202개 통과, 실패 0개.
- 개인 대화 생성 경합, 참여자 권한, 제3자 거절, 양방향 차단과 기록 보존을 실제 DB에서 확인했다.
- Ratchet 채널·개인 대화 구독의 참여자 검사, 메시지 없는 알림과 로그아웃 뒤 연결 종료를 확인했다.
- 채널·개인 대화의 파일 업로드, CSRF·참여자 검사, 최대 5 MiB 경계, 강제 다운로드와 원본 바이트를 확인했다.
- 상태 메시지, 정상·손상 PNG 사진 검증, 사용자 차단과 002~004 변경 도구의 보존·재적용 거절을 확인했다.
- 최초 전체 실행에서 GD 미활성으로 사진 검사 1개가 실패했다. 로컬 PHP 설정을 수정한 뒤 전체 검사를 다시 실행해 통과했다.

---
## 브라우저 확인

- 임시 검사 DB를 사용해 한글 사용자명 가입·로그인, 서버 생성과 채널 메시지 전송을 확인했다.
- 사용자 검색으로 개인 대화를 열고 메시지와 테스트 파일을 전송했다. 새로고침 후 대화 목록에서 다시 열어 메시지와 다운로드 링크를 확인했다.
- 프로필의 추가 정보 조회와 상태 메시지 저장을 확인했다.
- 위 브라우저 확인은 한 브라우저의 검사 계정으로 수행했다. 다른 기기에서의 동시 UI 확인과 운영 환경의 HTTPS·WSS는 수행하지 않았다.

---
## 남은 환경 확인

- 기존 개발 DB에는 002~004 변경을 적용하지 않았다. 사용자 데이터 백업과 적용 상태를 확인한 뒤 [로컬 실행 방법](LOCAL-SETUP.md)에 따라 적용한다.
- Ratchet 0.4.4는 PHP 8.3에서 동적 속성 관련 폐기 예정 경고를 출력한다. 자동 검사는 통과했으며 라이브러리 호환성 갱신이 필요하다.
- MySQL의 `max_allowed_packet`, PHP GD 확장과 업로드 한도는 각 개발 컴퓨터의 실제 설정을 확인한다.
