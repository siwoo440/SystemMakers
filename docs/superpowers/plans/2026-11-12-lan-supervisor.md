# 같은 Wi-Fi 개발 서버 자동 복구 계획

- 실제 Wi-Fi의 사설 IPv4를 확인하고 변경되면 새 주소의 웹·실시간 서버를 실행한다.
- 기존 DB·서버가 실행 중이면 보존하고, 감시기가 시작한 프로세스만 종료·재시작한다.
- 누락된 로컬 MySQL은 기존 데이터 폴더를 사용해 시작하며 초기화·마이그레이션은 하지 않는다.
- 사용자 로그인 시 감시기를 다시 실행하고, 현재 접속 주소와 장애를 개인 실행 폴더에 기록한다.
- 네트워크 선택과 기존 연결 보존, 중복 실행 방지, 프로세스 종료 후 복구를 확인한다.
- IP 변경 시 예전 링크는 작동하지 않을 수 있으며 컴퓨터 종료·절전과 인터넷 공개는 별도 조건이다.
