# 실시간 연결 조회 최적화 계획

- 목표: 실시간 구독 중 중복 HTTP 조회를 줄이고 메시지 누락과 연결 장애를 복구한다.
- 방식: 구독 중 안전망 조회는 15초, 연결이 없으면 기존 2초 간격을 사용한다. 오류 재시도와 채널별 권한 확인은 유지한다.
- 경합: HTTP 조회 도중 실시간 알림이 도착하면 현재 요청이 끝난 직후 한 번 더 조회한다.
- 서버: 세션과 채널 접근 권한을 감시하는 기존 0.5초 검사는 유지한다.
- 검증: 구독·종료 전환, 진행 중 알림, 오류·계정 전환과 개인·채널 대화를 테스트한다.
- 문서: 실제 동작과 검증 범위를 README와 실시간 문서에 기록한다.
