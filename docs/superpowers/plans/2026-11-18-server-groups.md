# 서버별 채널 그룹 구현 계획

> 서버와 채널의 기존 DB·API 구조를 유지합니다.

**목표:** 서버에 참여하면 해당 서버의 여러 채널과 기존 대화를 확인하고, 화면에서 소속 관계를 알아볼 수 있도록 표시합니다.

**구조:** 서버 멤버십으로 채널 조회 권한을 확인하며, 서버 선택과 초대 참여 뒤 개인 대화에서 서버 채널 화면으로 전환합니다. 서버 배너와 채널 목록을 하나의 테두리로 묶습니다.

**기술:** PHP, MySQL, JavaScript, HTML, CSS, WebSocket.

- [x] 서버 멤버십, 채널 목록과 대화 조회 구조를 확인합니다.
- [x] 초대 참여와 개인 대화 복귀를 회귀 검사하고 화면 전환을 연결합니다.
- [x] 서버 소속 채널을 하나의 화면 묶음으로 표시합니다.
- [x] 격리된 DB에서 초대 전후 권한과 전체 회귀 검사를 실행합니다.
- [x] 사용자 안내 및 API·DB 문서를 최신화합니다.
- [x] 작은 화면에서 양쪽 패널과 가운데 닫기 공간을 검증합니다.
