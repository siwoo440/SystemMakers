# 같은 Wi-Fi 공유 개발 계획

- 목적: 하나의 개발 서버와 DB를 같은 Wi-Fi의 팀원이 함께 이용한다.
- 기본 주소: 기존 루프백 설정을 유지하고 명시된 사설 IPv4 주소만 선택적으로 허용한다.
- 연결: 웹과 WebSocket 주소, 허용 출처, CSP와 브라우저 연결을 함께 설정한다.
- 검증: 기본 로컬 설정, 사설 주소, 공개 주소 거절, API 비공개 경계, 인증과 양방향 대화를 확인한다.
- 전제: HTTP와 ws는 암호화되지 않는다. 테스트 계정과 신뢰할 수 있는 Wi-Fi에서만 사용한다.
- 실제 DB는 초기화하거나 마이그레이션을 임의로 수행하지 않는다.
