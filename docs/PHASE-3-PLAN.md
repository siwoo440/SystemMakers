# 3단계 회원 인증과 웹 연동 계획

목표는 실제 MySQL 회원가입·로그인·로그아웃과 현재 웹 화면의 인증 연동이다. 사용자가 승인한 3단계 범위와 [API.md](API.md), [DATABASE.md](DATABASE.md)를 구현 기준으로 사용한다. 메시지는 계속 로컬 미리보기이며 저장·조회는 4·5단계다.

---
## 공통 규칙과 인터페이스

PHP·PDO·MySQL과 기존 동일 출처 fetch를 유지한다. 모든 코드 줄에 짧은 한글 명사형 주석과 Allman 스타일을 적용하고 중괄호만 있는 줄은 제외한다. 비밀 값은 Git에서 제외하며 main에 한국어 제목·상세 본문으로 커밋·푸시한다.

register.php는 username·email·password를 받아 201 data.user를 반환하며 자동 로그인하지 않는다. login.php는 email·password를 받아 200 data.user·data.csrf_token을 반환한다. logout.php는 빈 JSON 객체를 받아 200 data.message를 반환한다. 모든 POST는 세션별 CSRF를 검사한다.

사용자명은 영문·숫자·밑줄 3~32자, 이메일은 ASCII 최대 254자다. 둘 다 앞뒤 공백 제거 후 소문자로 저장한다. 비밀번호는 원문 그대로 12~64 코드 포인트·최대 72바이트·NUL 불허 조건으로 검사한다. ID는 문자열, 날짜는 UTC ISO 8601이다.

## 작업 1 실제 회원 API

담당 파일은 backend/api의 회원 API 3개, backend/includes의 계정·횟수 제한 모듈과 tests/auth.test.mjs다. 기존 공통 입력·세션·CSRF·PDO 처리를 재사용한다.

- [x] 실제 PHP·MySQL 테스트로 미구현 실패 확인.
- [x] 회원 검증·중복 검사·비밀번호 해시 저장과 UNIQUE 동시 충돌 처리.
- [x] 실제 해시 확인, 없는 계정과 오입력의 공통 401, 로그인 시 세션·토큰 교체.
- [x] 세션과 쿠키 삭제, 이전 쿠키·토큰의 인증 재사용 차단.
- [x] AUTH_RATE_LIMIT_KEY로 이메일·IP HMAC 키 생성, 공유 DB의 15분 고정 창 제한.
- [x] 이메일 5회·IP 30회, 성공 포함, 제한 시 추가 누적 없음, Retry-After와 동시 요청 검증.

## 작업 2 인증 화면 연동

담당 파일은 frontend/index.html·app.js·app.css다. 새 프레임워크나 정적 파일을 추가하지 않고 기존 화면을 확장한다.

- [x] 실제 가입·로그인·로그아웃 POST와 새로고침 후 세션 복원 연결.
- [x] 가입 후 로그인 화면 전환, 실제 사용자 표시, 로그아웃 시 사용자·초안·메시지 초기화.
- [x] 중복 제출·화면 전환 경쟁 방지, 접근 가능한 필드 오류와 네트워크 실패 안내.
- [x] CSRF 오류 후 토큰 재조회, 원래 POST 자동 반복 금지.
